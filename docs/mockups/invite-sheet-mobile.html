What changed and why

  1. Preview leads. The poster is the output; it sits at the top, fully visible, scaled to fit. In the screenshot it was cropped below the fold, which is the one thing a share sheet must never do.
  2. Format is a segmented control under the preview. It switches the thing directly above it, so the relationship is spatial rather than labelled. Drops the "FORMAT" eyebrow.
  3. Settings are rows, not a form. "When" is one row with a value, tapping opens the native picker. Replaces a toggle plus two native inputs that fought the design system. If the date isn't decided, the line is simply absent from the poster. Same for Where. The poster only says what the host actually knows; nothing on it is a placeholder.
  4. Where and Headline rows expose the two other things the poster says, so the host can fix a wrong headline here instead of closing the sheet and going back to the shelf.
  5. Link row with copy covers the case where the host wants to paste text into a chat instead of an image.
  6. One primary action. Share is gold and full width; Save PNG is a quiet text button. Two equal-weight buttons made the sheet ask a question it should already know the answer to.
  7. Header uses a close icon instead of "CLOSE" in mono caps. Sentence case everywhere. No eyebrow labels.
